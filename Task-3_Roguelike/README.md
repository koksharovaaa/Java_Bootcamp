# Java Bootcamp: Roguelike

Консольная roguelike-игра в духе Rogue 1980 года: 21 уровень, генерация комнат и коридоров, пошаговый бой с различными врагами, туман войны, инвентарь с предметами, которые можно использовать, сохранение прогресса и таблица рекордов.

## Стек
- Java 21
- Google Lanterna
- JSON

## Слои
- domain: игровая логика
- presentation: отрисовка, управление
- datalayer: сохранение и загрузка

## Запуск
./bash rogue.sh

## Управление
- WASD: передвижение
- H: вкладка с оружием
- J: вкладка с едой
- K: вкладка с эликсирами
- E: вкладка со свитками
- P: пауза
- Q: выход из игры
