# Java Bootcamp: Изучение основ языка

Набор простых задач на Java: математические вычисления, работа с массивами, файлами и строками.

## Стек
- Java 18
- Gradle (Kotlin DSL)

## Запуск
Каждое задание это отдельный Gradle-проект.

cd exerciseN
./gradlew run

## Составляющие проекта
- Периметр треугольника
- Секунды в hh:mm:ss
- Числа Фибоначчи (рекурсия)
- Среднее арифметическое отрицательных
- Числа с одинаковой первой и последней цифрой
- Сортировка выбором
- Min/max из файла
- Проверка последовательности на возрастание
- Фильтрация строк
- Поиск через Stream API
