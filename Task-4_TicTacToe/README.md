# Java Bootcamp: TicTacToe REST API

Веб-приложение для игры в крестики-нолики против компьютера. Для ходов компьютера используется Алгоритм Минимакс, а для хранения игр, которые стираются после выхода из программы, используется класс хранилище и репозиторий для работы с ним.

## Стек
- Java 21
- Spring Boot

## Слои
- web: контроллеры, DTO, мапперы
- domain: игровая логика, сервисы
- datasource: сущности, репозитории, классы-хранилища
- di: конфигурация Spring

## Запуск
1. ./gradlew bootRun
2. Отправлять запросы в соответствии с request-форматами

## Основные endpoint'ы
- POST /game/{uuid}: создание игры, ход
